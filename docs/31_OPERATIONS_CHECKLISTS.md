# Operations Checklists

## Daily
- review critical alerts, failed jobs, queue age, quota freshness, backup freshness, disk and TLS.
## Per release
- confirm commit/digest, migrations, tests, UAT, backup, approval, rollback and post-deploy checks.
## Monthly
- provider plan/quota/terms verification, access review, dependency/security review, restore drill schedule, capacity report, billing reconciliation.
## Client offboarding
- stop renewals as contracted, export deliverables/data, revoke credentials, remove DNS/routes, retain/delete data per contract/law, preserve audit, destroy volumes only after approval and verified backup/export.
