# Legal, Licensing and Data Rights

Record client authorization for data processing and external provider use. Maintain data processing terms, purpose, retention, deletion and export. Track third-party code/asset licenses, SBOM, attribution obligations and source ownership. Contract must state client IP transfer, pre-existing/reusable components, open-source dependencies, portfolio rights and handover conditions. Obtain legal/CA review for India DPDP, tax, marketing consent, platform terms and cross-border processing.
