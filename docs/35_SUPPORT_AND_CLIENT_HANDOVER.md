# Client Handover and Support Runbook

Handover includes source repository ownership/access, release digest, architecture overview, environment variables by secret reference (not secret values in documents), database schema/migration state, backup/restore instructions, domain/DNS, third-party accounts, license inventory, known limitations, operational contacts and acceptance record.

For client-owned production, client retains provider billing and root ownership; Aknja receives scoped deployment access. Revoke temporary access after handover if no maintenance contract remains. For Aknja-managed hosting, hosting terms and renewal/cancellation are explicit.
