# Capability Registry

Use one Central AI Orchestrator and dynamic task-scoped specialist workers. Do not instantiate the legacy 26-agent model as permanent services.

Initial capability templates:
1. Planning & requirements analyst.
2. Software engineering & integration.
3. QA, code review & security verification.
4. Research & documentation.
5. DevOps, deployment & recovery.
6. Business operations & client communication.
7. UI/UX and creative production.
8. Digital marketing and SEO.
9. Analytics and CRO.
10. Support and maintenance.

These are logical capability definitions, not employees or always-running services. Each run has a scoped task, allowed tools, budget, deadline, input references, output schema and verifier. Least privilege is enforced by the Tool Gateway.
